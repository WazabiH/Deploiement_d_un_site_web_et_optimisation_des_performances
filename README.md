# Déploiement d'un site web et optimisation des performances

## Présentation

Ce projet a été réalisé dans le cadre de ma formation en BUT Métiers du Multimédia et de l'Internet (MMI).

L'objectif était de mettre en ligne un site web statique tout en appliquant différentes techniques d'optimisation afin d'améliorer les performances de chargement et l'expérience utilisateur. Le projet prend la forme d'un site vitrine présentant une agence de voyage fictive.

## Objectifs du projet

* Déployer un site web sur un serveur.
* Optimiser les ressources du site.
* Réduire les temps de chargement.
* Améliorer les performances web.
* Comprendre l'impact des médias sur l'expérience utilisateur.
* Appliquer les bonnes pratiques d'intégration web.

## Fonctionnalités

* Site web responsive.
* Présentation d'offres de voyage.
* Mise en page structurée et accessible.
* Navigation adaptée aux différents supports.
* Optimisation des images et des ressources.

## Optimisations réalisées

Plusieurs améliorations ont été mises en œuvre afin d'améliorer les performances du site :

* Conversion des images vers des formats plus légers.
* Réduction du poids des ressources.
* Préchargement des éléments essentiels à l'affichage.
* Adaptation de l'affichage aux différentes tailles d'écran.
* Structuration du code pour faciliter la maintenance.

## Installation

Cloner le dépôt :

```bash

```

Ouvrir ensuite le fichier `index.html` dans un navigateur web.
